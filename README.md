## 🛠️ Getting Started

### Prerequisites
- Node.js 14+ and npm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Skumarbn/products-expiry-tracker.git
   cd products-expiry-tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```
   
4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 📱 Complete Usage Guide

### 🎯 **Getting Started**
1. **Add Your First Product**: Use the Quick Add form on the dashboard
2. **Enable Notifications**: Go to Settings → Enable browser notifications
3. **Explore Features**: Navigate through all 6 main pages using the sidebar

### 📦 **Product Management**
- **Adding Products**: Use autocomplete from 90+ common items, select expiry dates
- **Editing**: Double-click product names or dates for inline editing
- **Bulk Operations**: Select multiple products for batch deletion or Amazon ordering
- **Search & Filter**: Real-time search with status-based filtering (Fresh/Expiring/Expired)
- **Export/Import**: Backup your data as JSON files for safety

### 🛒 **Grocery List Features**
- **Smart Suggestions**: System automatically suggests expired/expiring products
- **Manual Addition**: Add any grocery items to your shopping list
- **Organization**: Items are grouped as "To Buy" and "Completed"
- **Editing**: Double-click item names to edit them inline
- **Progress Tracking**: Visual statistics show completion progress

### 🛍️ **Amazon Integration**
- **Quick Reorder**: Dedicated page shows all expired/expiring products
- **Individual Ordering**: Click "Order Now" on any expired/expiring product
- **Bulk Orders**: Order multiple products simultaneously from the bulk actions
- **Smart Search**: Amazon searches optimized for grocery and fresh items

### 📊 **Analytics & Insights**
- **Timeline View**: 30-day forecast showing when products expire
- **Status Charts**: Visual breakdown of fresh vs expiring vs expired
- **Success Tracking**: Monitor your inventory management effectiveness
- **Activity Feed**: Track recent additions and changes

### 🔔 **Notification System**
1. **Setup**: Navigate to Settings → Toggle notifications → Click "Enable"
2. **Automatic Alerts**: Receive browser notifications 3 days before expiry
3. **Hourly Checks**: System monitors products every hour automatically
4. **Management**: Toggle notifications on/off anytime in settings

### 💾 **Data Management**
- **Auto-Save**: All data automatically saved to browser storage
- **Export**: Create JSON backups of all your products
- **Import**: Restore from backup files with duplicate detection
- **Clear Data**: Complete reset option with confirmation prompts

### 🎨 **Navigation & Interface**
- **Dashboard**: Overview with statistics, quick add, and recent products
- **Grocery List**: Smart shopping list with suggestions and tracking
- **Products**: Full product management with cards, editing, and bulk actions
- **Quick Reorder**: Amazon integration hub for expired/expiring items
- **Analytics**: Visual charts and insights about your inventory
- **Settings**: Notifications, data management, and preferences
