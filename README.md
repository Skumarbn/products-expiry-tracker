# FreshTrack Pro – Product Expiry Tracker

A modern, minimalist, and professional React app to track expiry dates for products, with browser notifications, autocomplete, and accessibility features.

---

## 🚀 Features

- **Modern UI/UX**: Clean, responsive, and accessible design with glassmorphism and vibrant gradients
- **Product Tracking**: Add, edit, and remove products with expiry dates
- **Autocomplete**: Smart suggestions for common items as you type
- **Inline Editing**: Double-click to edit product name or expiry date directly in the list
- **Browser Notifications**: Get notified before products expire (no backend required)
- **Accessibility**: Keyboard and screen reader friendly
- **No Backend Needed**: All features work in the browser

---

## 🛠️ Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Skumarbn/products-expiry-tracker.git
   cd products-expiry-tracker
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm start
   ```
   The app will be available at [http://localhost:3000](http://localhost:3000)

---

## ✨ Usage

- **Add a product:** Enter the product name (use autocomplete or type your own) and expiry date, then click "Track".
- **Edit inline:** Double-click a product name or expiry date to edit it.
- **Enable notifications:** Click "Enable Notifications" in the Browser Notifications card to get expiry alerts.
- **Remove a product:** Click the ❌ button next to a product.
